## 1. Descripción del Proyecto
Controlador físico interactivo de diseño industrial inspirado en sintetizadores y pedales de efectos[cite: 2]. Integra controles analógicos y discretos conectados en tiempo real a una interfaz web (Dashboard GUI) desarrollada con Web Audio API y comunicación Serial[cite: 2, 6].

---

## 2. Hardware y Electrónica
El dispositivo cuenta con:
* **Inputs:** 1 Fader deslizante, 1 Potenciómetro circular (tono), 1 Botón A (Play/Mute) y 1 Botón B (Tipo de onda)[cite: 5, 6].
* **Shield Modular:** Toda la electrónica está soldada sobre una placa PCB preperforada con pines *headers*, permitiendo desacoplar el Arduino sin desoldar componentes (cero protoboards)[cite: 2].
